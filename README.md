Synergy Health Plus

Overview

Synergy Health Plus is a web application designed to assist users in tracking and managing their health. The app provides tools to calculate and monitor activity levels, blood pressure, diet, BMI, and other health-related metrics.

Features

Activity Tracker: Logs daily activities and provides insights.

Blood Pressure Monitor: Helps users track and analyze blood pressure readings.

Diet Planner: Suggests meal plans based on user preferences and health goals.

BMI Calculator: Computes BMI based on height and weight.

User-friendly Interface: Built with HTML, CSS, and Python for seamless user experience.

Technologies Used

Frontend: HTML, CSS

Backend: Python (Flask/Django)
